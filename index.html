复制到公众号之后

三条真实可用的路径，按成功率排序。
  1. 富文本直粘：本页【一键复制全文】→ 公众号后台正文 Ctrl+V。96 编辑器的教程即采用此路径（「点击微信复制，然后 Ctrl+V 粘贴到微信公众平台」）。范围大时建议先在下拉里选「当前页」试粘。
  2. HTML 源码模式：安装 Chrome 扩展 wechat-mp-html-source-helper，在编辑页打开「HTML 源码」→ 粘贴【复制全文 HTML 源码】的内容 → 插入到光标位置。该扩展明确保留常见 SVG 图形与 SMIL 动画。
  3. 第三方编辑器中转：秀米 / 135 / E2.COOL 的「HTML 源码组件」→ 同步到公众号草稿箱。
必须知道的风险：微信后台会二次清洗标签、属性和样式，最终结果可能与原始 HTML 不一致；扩展作者也注明「保留代码不代表微信一定接受」。请保存草稿后重新打开，并在 iOS + Android 真机的浅色 / 深色预览中验收。本仓库未在真实公众号账号下完成发布验收，不声称"已上线可用"。
